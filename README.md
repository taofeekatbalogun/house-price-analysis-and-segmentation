# 🏠 House Price Analysis & Market Segmentation

## 📌 Overview
This project analyzes housing data to understand price drivers and applies machine learning techniques to both predict house prices and segment the housing market.

## 🎯 Objectives
- Perform exploratory data analysis (EDA)
- Build a regression model to predict house prices
- Apply clustering to segment the housing market

## 🛠️ Tools
- Python (pandas, scikit-learn)
- matplotlib, seaborn

## 📊 Key Insights
- Number of rooms strongly influences house prices
- Higher LSTAT values are associated with lower prices
- Crime rate negatively impacts property value
- Houses can be grouped into affordable, mid-range, and premium segments
